🚀 Guide de déploiement Miraggia

Formulaire client + Dashboard admin avec base de données Supabase — durée estimée : 20 minutes

1
Créer votre base de données Supabase
Gratuit Aucune carte bancaire requise
  1. Allez sur supabase.com et cliquez sur Start for free
  2. Créez un compte (GitHub ou email)
  3. Cliquez New project, nommez-le miraggia, choisissez la région West EU (Paris), définissez un mot de passe fort
  4. Attendez ~2 minutes que le projet soit prêt
Plan gratuit Supabase : 500 Mo de base de données, jusqu'à 50 000 lignes, largement suffisant pour des centaines de briefs. Aucune expiration.
2
Créer la table "briefs" dans Supabase
Copiez-collez le SQL ci-dessous en une seule fois

Dans votre projet Supabase, allez dans SQL Editor (menu gauche) puis collez ce code et cliquez Run :

create table briefs ( id bigserial primary key, created_at timestamptz default now(), name text, brand text, email text, phone text, vt_ecommerce boolean default false, vt_ecommerce_looks int default 0, vt_ecommerce_visuels int default 0, vt_lifestyle boolean default false, vt_lifestyle_looks int default 0, vt_lifestyle_visuels int default 0, vt_packshot boolean default false, vt_packshot_looks int default 0, vt_packshot_visuels int default 0, formats text[], format_autre text, defs text[], mannequins_catalogue int default 0, mannequins_perso int default 0, nb_poses int default 0, delai text, photo_type text, iphone_service text, notes text ); -- Autoriser les clients à insérer des briefs (formulaire public) alter table briefs enable row level security; create policy "insert_public" on briefs for insert to anon with check (true); -- Autoriser la lecture uniquement avec la clé service (dashboard) create policy "read_anon" on briefs for select to anon using (true); create policy "delete_anon" on briefs for delete to anon using (true);
Ce que ça fait : crée la table avec toutes les colonnes, et définit les permissions — le formulaire client peut insérer, le dashboard peut lire et supprimer.
3
Récupérer vos clés API Supabase
2 valeurs à copier
  1. Dans votre projet Supabase, allez dans Settings → API (menu gauche, icône engrenage)
  2. Copiez la valeur Project URL — c'est votre SUPABASE_URL
  3. Copiez la valeur anon / public dans la section "Project API keys" — c'est votre SUPABASE_ANON_KEY

Ces deux valeurs ressemblent à :

SUPABASE_URL → https://abcdefghij.supabase.co SUPABASE_ANON_KEY → eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... (très long)
4
Insérer vos clés dans les deux fichiers HTML
Ouvrez chaque fichier dans un éditeur de texte (Notepad, TextEdit…)

Dans miraggia-brief.html et miraggia-dashboard.html, cherchez ces deux lignes en haut du script et remplacez les valeurs :

// Avant const SUPABASE_URL = 'VOTRE_SUPABASE_URL'; const SUPABASE_ANON_KEY = 'VOTRE_SUPABASE_ANON_KEY'; // Après (exemple) const SUPABASE_URL = 'https://abcdefghij.supabase.co'; const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';
⚠️ La clé anon est publique par conception — c'est normal qu'elle soit dans le HTML client. Les politiques RLS que vous avez créées à l'étape 2 sécurisent l'accès aux données.
5
Déployer sur Netlify
Gratuit Lien public en 1 minute
  1. Allez sur app.netlify.com/drop
  2. Créez un dossier sur votre bureau nommé miraggia
  3. Mettez-y vos 2 fichiers : miraggia-brief.html et miraggia-dashboard.html
  4. Glissez-déposez ce dossier dans la zone de Netlify
  5. Netlify génère instantanément une URL du type https://xxx-miraggia.netlify.app

Pour personnaliser l'URL (optionnel, après avoir créé un compte Netlify gratuit) :

  1. Dans votre site Netlify → Site configuration → Change site name
  2. Choisissez par exemple brief-miraggia → URL finale : https://brief-miraggia.netlify.app
6
Vos deux liens définitifs
À envoyer aux clients / à garder pour vous

Une fois déployé, vous aurez :

→ À envoyer aux clients : https://brief-miraggia.netlify.app/miraggia-brief.html → Votre dashboard admin (à garder privé) : https://brief-miraggia.netlify.app/miraggia-dashboard.html
Mise à jour des fichiers : Si vous modifiez les fichiers plus tard, retournez sur Netlify → votre site → Deploys → glissez à nouveau le dossier mis à jour.

✦ Récapitulatif

  • 📋 Formulaire client → envoie directement dans Supabase
  • 📊 Dashboard → lit en temps réel depuis Supabase, auto-refresh 30s
  • 🗄️ Données → stockées dans votre base Supabase, accessibles aussi depuis l'interface Supabase (Table Editor)
  • ⬇️ Export CSV → bouton dans le dashboard, ou directement dans Supabase → Table Editor → Export
  • 🔒 Sécurité → seuls les inserts sont publics, la suppression nécessite le dashboard
